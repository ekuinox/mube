# TASK-7: ギア伝達＋ロストモーション・フォーク（手動解錠の軽量化）設計

手動でサムターンを回すとサーボのギア列を逆駆動することになり、重い。
本スペックは、サーボとサムターンの常時剛結をやめ、遊びを持つフォークで必要時だけ押す機構（**ロストモーション・クラッチ**）と、サーボを横並びに置くギア伝達への変更を定める。
着想は参考記事[^ref]のクラッチ機構と「サーボのギア化（横並び配置）」による。

[^ref]: https://dreamerdream.hateblo.jp/entry/2022/09/22/180000 （クラッチ機構）と前日記事 https://dreamerdream.hateblo.jp/entry/2022/09/21/180002 （ギア化）。なお参考記事のギアは横並び配置が目的で、増速目的とは書かれていない。ギア比や可動域の記載もない。

## 前提となる事実

- 電源ゲート（GP14 ローサイド MOSFET）はファーム側で「整定 → PWM 停止 → 給電断」まで実装済み。
  ただし回路はローサイド切りのため**給電カットは完全ではない**。
  +5V はサーボに繋がったままで、信号線経由の回り込み（phantom 給電）が残る（2026-07-19 スペックの棚上げ項目「待機時 phantom 給電のハイサイド化」として既知）。
- したがって手動時の重さの要因は二つありうる。
  無給電でも残るギア列の逆駆動摩擦と、phantom 給電による電気的な抵抗である。
  切り分けは実機検証で行う（サーボを回路から完全に切り離した状態と、現回路に組んだ状態で逆駆動トルクを比較する）。
  なお本設計のクラッチ化は手動時にサーボを逆駆動しないため、どちらが主因でも手動の軽さは成立する。
- SG90 の位置検出は出力軸直結のポテンショメータによる絶対位置。
  手で回しても原点はズレず、次の PWM 指令で指令角へ復帰する。再校正は不要。
  手動操作の実害は「重さ」と、乱暴に回した場合のナイロンギア摩耗に限られる。
- 実機確定値（2026-07-19 スペック）: `SERVO_MIN_US=1000` は既にメカ端。
  パルス拡張の余地は高パルス側（2000µs → 最大 2400µs 程度）にしかない。
  直結 90° ストロークでは throw もトルクも足りている。
- サムターンは 90° バネ戻りタイプ（途中保持なし）。安定位置は両端の 2 点のみ。
- ボディ（ペデスタル・プレート）は別途見直し予定があり、本タスクで作り直してよい（ユーザー確認済み 2026-07-23）。

## 機構の幾何

手動で 90° を自由に回すには、フォークの 2 爪の間にノブのストローク 90° をまるごと飲み込む遊びが要る。
遊びが 90° 未満だと、手動の途中で爪に当たり、そこから先はサーボを引きずることになるからだ。

一方サーボ駆動では、施錠に使う爪と解錠に使う爪が反対側にあるため、片道の動作は「遊びを渡る空走（約 90°）＋押し切り（90°）」になる。
したがってフォーク側の必要可動域は **180°＋退避マージン（10〜15°）**。
ノブの角幅は遊びの必要量に足される一方で押し切り位置からは引かれ、相殺して式に残らない。

SG90 の実効可動域は低パルス側がメカ端のため 180°+α に届く見込みが薄い。
そこでギア対に増速比を持たせ、サーボの実可動域 × 比 ≧ 190° を満たす。
比は実測した可動域から決める（後述）。増速はトルクを比で割るため、必要最小限に留める。

## 要件

1. 手動操作は「掴んで回すだけ」。全 90° ストロークでサーボの抵抗を受けない。
2. 電動操作は従来どおり LOCK/UNLOCK を完遂し、動作後は毎回ニュートラル位置へ復帰して爪をノブの経路外に退避させる。電源ゲート運用は維持する。
3. ノブ先端は露出させ、指で掴める掛かりを確保する（根元の数 mm だけをフォークが囲う）。
4. ギア比・遊び角・押し切り角・ニュートラル角はすべて params / キャリブ定数としてパラメタ化し、実機合わせは安全側から詰める。
5. 印刷は A1 mini（0.4 ノズル）。ギア歯は同プリンタで成立するモジュールを選ぶ。

## 設計

### 1. ギア対（横並び配置）

- サーボはロゼット中心の真上から横へオフセットし、ペデスタルごと横並びに置く。
- サーボホーン側に**駆動ギア（大）**、サムターン軸中心に**従動リングギア（小）**を置く平歯車 1 段。
  歯形はインボリュートを OpenSCAD モジュールとして新設する（`enclosure/models/gears.scad`）。
- リングギアは中央が開いた環状で、内径はノブ台形断面の回転包絡＋クリアランスから決める。
  軸受けは固定側部品の円筒面によるプリント滑り軸受けとし、軸方向は抜け止めリップで拘束する。
- ギア比（駆動歯数 / 従動歯数）は params 化する。初期値は実測前の仮置きで 1.5。
  確定値は「フォーク側 190° ÷ サーボ実効可動域」の切り上げとし、トルク（1.8kg·cm ÷ 比）を無駄に減らさないよう最小で選ぶ。
- 噛み合いのセパレーション反力はペデスタルの剛性で受ける。軸間距離は params で一元管理し、バックラッシュは印刷クリアランスとして params 化する。

### 2. ロストモーション・フォーク

- リングギア下面（ドア側）に 2 枚の爪を立てる。ノブ根元の掛かりは数 mm（参考記事は約 2mm）に抑え、先端は露出させる。
- 爪間の自由角 = 90°（ストローク）＋接触半径でのノブ角幅＋マージン。params 化する。
- ニュートラル位置は自由角の中央とし、両端どちらのノブ位置からも手動 90° が爪に触れないことを assert で担保する。

### 3. ペデスタル・ボディの再設計

- 天板をオフセット距離ぶん横へ延長し、サーボの M2 耳ネジ固定（下穴 2.2、セルフタップ）は流用する。
- 現行ソケットの押さえ爪・キャプチャ壁はホーン剛結を前提とした機構なので廃止し、役割は「リングギアの軸受けと抜け止め」に置き換わる。
- ボディ・プレート・トレイとの取り合いは、別途予定されているボディ見直しと合流させてよい。本タスクの必須範囲は「ギア対＋フォーク＋それを保持するペデスタル」まで。

### 4. ファームウェア / コア

- `mube-core/src/servo_math.rs` に `NEUTRAL_DEG` と押し切り角（LOCK 側 / UNLOCK 側）を追加する。
  ギア 1 段で回転方向が反転するため、方向の吸収も定数側で行う。
- 動作シーケンスを「給電 ON → 押し切り角へ → 整定 → ニュートラルへ → 整定 → PWM 停止 → 給電 OFF」に変更する（`mube-firmware/src/servo.rs`）。
- SG90 は絶対位置復帰するため、手動操作後の特別処理は不要。
  シーケンスと角度変換は host テストで検証する。

### 5. 実機検証の順序

1. 逆駆動トルクの切り分け（AC #3）。サーボを回路から完全に切り離した状態と、現回路に組んで給電ゲート OFF の状態で、手で回す重さを比較する。phantom 給電の寄与を記録する。
2. 高パルス側の実効上限を安全側から実測する（2000µs から刻んで上げ、唸り・メカ端を確認）。ここでギア比を確定する。
3. ギア対だけをクーポン印刷し、噛み合い・バックラッシュ・空転トルクを確認する。
4. フォーク付きリングギアで、手動 90° が無抵抗で回ることと、電動の押し切り → ニュートラル復帰を確認する。
5. 施錠負荷での完遂を確認する。トルク不足なら比を下げるか、同寸で高トルクの MG90S（金属ギア 2.2kg·cm）への換装を次候補とする。

## 制約・スコープ外

- STATUS はファームが記憶する状態を返すため、手動操作後に実状態とズレうる。
  これは現行の直結でも同じで、状態センサの追加は別タスクとする。
- 給電カットの完全化（ハイサイド化）は別 issue のまま維持する。
  クラッチ化すれば手動時にサーボを逆駆動しないため、手動の軽さは給電カットの完全性に依存しない。
- 2026-07-19 スペックで棚上げしたギア機構をここで再開する。
  ただし再開理由は当時懸念した throw / トルク不足ではなく、手動操作の重さの解消である。
