# ユニバーサル基板化＋全体カバー 筐体改修 設計書

日付: 2026-08-16

ブランチ: `enclosure/universal-pcb-with-lid`

関連: TASK-4（回路のユニバーサル基板化）、TASK-6（本体上部が重く固定が上から剥がれてくる）

## 目的

1. 電子部品の実装をブレッドボードからユニバーサル基板 P-03229（72×47mm）へ移す。トレイをその基板マウントに作り替える。
2. 配線がむき出しの現状をやめ、プレート上の全部品を覆う一体カバーを新設する。
3. 上記に伴いプレート外形を再設計する。ブレッドボードと Pico を横並びに置く前提が消えるため、大幅に縮められる。

## 背景

- 現行は「オープンベースプレート」構成（PR #79）。プレート（`body.scad`）にペデスタル・ソケット・トレイをボルトオンし、外周壁も蓋も持たない。配線は完全に露出している。
- 現行トレイはハーフサイズのブレッドボード（85.5×54.5）と Pico（51×21）を **横並び** に載せる前提で、これがプレート 115.8×153.1mm という大きさを決めていた。
- TASK-4 で「Pico は基板に直付けせず、Pico 側にオスピンヘッダ・基板側にメスソケットで抜き差しする」ところまで決まっている。Pico が基板の上に重なるので、電子部品エリアのフットプリントは基板 1 枚ぶん（72×47）に縮む。
- P-03229 の既製マウント穴は φ3.2、中心間ピッチ 長辺 66mm × 短辺 41mm（docs/parts-selection.md）。

## 決定事項

ブレインストーミングで確定した内容。

- カバーは **1 部品**。サーボ・ペデスタル・基板・配線のすべてを覆う。
- 屋根は **+Y 方向への単一勾配（45°）**。水平な段は作らない。
- カバーの固定は **M2 × 4 本**。カバー裾の外側に張り出した耳を、プレート四隅のラグへ落とす。
- カバー開口は **LED 窓・タクトスイッチ・USB 切欠き** の 3 つ。サムターンの手動操作窓は設けない（手動操作はカバーを外して行う）。
- **トレイは残す**。基板を机上で組んでからプレートへ載せられる利点を維持する。カバーとは独立に着脱できる。
- 基板は **横置き**（長辺 72 を X 方向）。縦置きよりプレートの Y 方向が短くなり、重心が低くなる。

## 平面レイアウト

### 基板（P-03229, 72 × 47）

世界座標で X: −27〜45、Y: 30〜77。中心は (9, 53.5)。

- −Y 端がペデスタル受けカーブ外周（`ped_curb_ro` = 27.7）から 2.3mm 逃げる。
- 既製マウント穴 4 個は基板ローカルで (±33, ±20.5) ＝ 世界座標 (−24, 33) (42, 33) (−24, 74) (42, 74)。

### 基板上の部品配置（基板ローカル座標）

| 部品 | 位置 | 根拠 |
| --- | --- | --- |
| U1 Pico W | 長辺を X に、Y 中央。x −15〜+36 | USB を基板 +X 端に face させる。メスソケット列が y = ±8.89 に来るので既製穴（y = ±20.5）と干渉しない |
| D1 2色LED | (−24, +21) ＝世界 (−15, 74.5) | 屋根が最も低い +Y 端。足を伸ばして屋根の穴へ頭を出す |
| SW1 タクト | (−10, +21) ＝世界 (−1, 74.5) | 同上。ボタンキャップで屋根まで渡す |
| Q1 MOSFET | (−30, −16) | 背が高い（基板上 16mm）ので屋根の高い −Y 側へ |
| C1 470µF | (−30, −5) | 同上 |
| サーボ 3pin | (0, −21) ＝世界 (9, 32.5) | 基板の −Y 端。ペデスタルが隣なのでケーブルが最短で降りる |
| Rg / Rgs / Rled ×2 / C2 / D2 | 残りの帯（y −23.5〜−10.5、x −36〜−15） | 背が低いので配置自由度が高い |

Pico を基板の +X 端まで寄せると、(33, 20.5) の既製穴が Pico の影に入る。Pico はソケットで基板上 9.5mm に浮くので M2 なべ小ねじの頭（高さ約 1.3mm）とは当たらないが、**基板を 4 本のネジで留めてから Pico を挿す** 順序を守る必要がある。組立手順に明記する。

### トレイ

- 床: X −27.5〜45.5、Y 21.5〜85.5、厚さ 2.4。原点まわりを半径 29 で丸く欠き取り、ペデスタル受けカーブ（半径 27.7、高さ 2.4）をまたぐ。
- 基板支柱 4 本: 世界座標 (−24, 33) (42, 33) (−24, 74) (42, 74)、高さ 5、外径 5、下穴 φ2.1（`tray_screw_pilot` と同仕様）。
- プレート固定スリーブ 4 個: (−22, 25.5) (40, 25.5) (−22, 81.5) (40, 81.5)。既存の `m2_sleeve_solid()` / `m2_sleeve_cuts()` をそのまま流用する。

固定スリーブを基板の ±Y 側に置いたのは、±X 側に置くとプレートの −X 端がドア枠へ寄りすぎるため。−X 側は `clear_left` = 50 の制約があり、カバーの裾と耳を積み上げると余裕がなくなる。±Y 側は制約が緩い。

### プレート

- 本体外形: X −32.7〜50.5、Y −32.7〜90.5（83.2 × 123.2mm）、角R2、厚さ 2.4。
  - −X / −Y 端はカバー裾の外面（−30.7）＋ 2mm。
  - +X 端はカバー裾の外面（48.5）＋ 2mm。+Y も同様（88.5 + 2）。
- カバー固定ラグ 4 個: 四隅の対角方向へ φ9 の円を張り出し、外形とフィレットで融合させる。中心は (−33.5, −33.5) (51.3, −33.5) (−33.5, 91.3) (51.3, 91.3)。各軸 2.8mm ずつ外へずらしてあり、円がカバー裾の角にちょうど接する。
- 中央ロゼット開口・ペデスタル受けカーブ・ペデスタル固定ボス 4 本は現行のまま不変。
- トレイ固定ボス 4 本とカバー固定ボス 4 本は `m2_boss()` を流用（高さ 6、袋下穴でドア面を貫通しない）。
- 上面リブ: 外周一周＋横桟。外周リブ（輪郭の内側 2mm、高さ 4）が **カバー裾の位置決めリップを兼ねる**。リブの内面（−30.7 / 48.5 / 88.5）がカバー裾の外面を受け、カバーがリブ環の内側に落ちる。横桟の y はトレイ床（y ≥ 21.5）とペデスタルスリーブ帯を避けて置き直す。

ラグを含めた最外は −X 側 −38.0、−Y 側 −38.0、+X 側 55.8、+Y 側 95.8。ドアクリアランス（`clear_left` = 50、`clear_down` = 65）に対してそれぞれ 12.0mm / 27.0mm の余裕が残る。

## カバー

### 外形

footprint は角R2 の矩形。内面 X −28.7〜46.5、Y −28.7〜86.5。壁厚 2.0 で外面 X −30.7〜48.5、Y −30.7〜88.5。

屋根は y ≤ 28.7 の範囲が水平（外面 z = 75.0）で、そこから +Y へ 45° で降りる。

```
 z(内面)
 73 ┤   ┌────────┐
    │   │ サーボ  ╲
    │   │         ╲ 45°
 48 ┤   │          ╲              ← Pico 直上。スタック 23.4 に対し余裕
    │   │           ╲
 27 ┤   │            ╲____        ← LED / SW（世界 y 74.5）。基板上 15.8mm
 15 ┤   │                 ╲|      ← +Y 端の壁（内面 y 86.5 で z 15.2）
  0 ┴───┴──────────────────┴──→ y
   -28.7 28.7              86.5
```

内面天井の高さは `z = 73.0 − max(0, y − 28.7)`。主要な干渉点の余裕:

| 位置 | 部品上端 | 屋根内面 | 余裕 |
| --- | --- | --- | --- |
| 世界 y 37.5（MOSFET） | 27.4 | 64.2 | 36.8 |
| 世界 y 53.5（Pico USB） | 23.4 | 48.2 | 24.8 |
| 世界 y 74.5（LED / SW） | 16.4（SW 頭） | 27.2 | 10.8 |
| 世界 y 81.5（トレイスリーブ） | 12.2 | 20.2 | 8.0 |
| 世界 y 85.5（トレイ床 +Y 端） | 4.8 | 16.2 | 11.4 |

### 開口

| 開口 | 位置 | 寸法 |
| --- | --- | --- |
| USB 切欠き | +X 壁、中心 (46.5, 53.5, 22.2) | Y 方向 14 × Z 方向 10 |
| LED 窓 | 屋根、世界 (−15, 74.5) | φ5.2。内側に φ5.4 のガイド筒を 6mm（屋根内面 27.2 から 21.2 まで） |
| スイッチ穴 | 屋根、世界 (−1, 74.5) | φ6.4。内側に φ6.6 のガイド筒を 6mm（同上） |

LED（φ5、本体高さ 8.6）は基板に直付けだと上端が基板上 8.6mm にしかならず、屋根内面（基板上 15.8mm）に届かない。足を約 7.2mm 伸ばして立て、本体の上 6mm がガイド筒に入る状態にする。筒が頭の横ズレを止める。

ガイド筒はいずれも屋根の**内側**へ出す。カバーは天面をベッドに伏せて刷るので、屋根の外側へ出る突起は印刷できない。

### 固定

裾の外面から張り出す耳 4 個。耳の実体は `m2_sleeve_solid()` / `m2_sleeve_cuts()` をそのまま流用する（ボス逃げボア＋自己サポートファンネル＋頭ザグリ、トレイとペデスタルで実機検証済みの構造）。中心はプレートのラグ中心と一致させる。

裾はプレート上面（z = 2.4）に着地し、内面が外周リブ（高さ 4）の外面に嵌まって XY 位置決めされる。ネジは抜け止め専任。

## ボタンキャップ（新規の小部品）

タクトスイッチの頭は基板上 5mm（世界 z 16.4）で、屋根内面（世界 z 27.2）まで 10.8mm 足りない。屋根の穴から差し込む押し込み棒で渡す。

- 軸 φ6.0、全長 14.3。下端がスイッチの頭（世界 z 16.4）に乗り、上端が屋根外面（同 29.2）から 1.5mm 突出して 30.7 に来る。
- 抜け止めフランジ φ9 × 厚さ 1.2 を軸の途中に設ける。上面が世界 z 20.7 ＝ ガイド筒の下端（21.2）より 0.5mm 下。引き抜くと筒の下端に当たって止まる。押し込み側はスイッチの頭が受けるので落ち込まない。
- 押し代 0.5mm。タクトスイッチのストローク 0.25mm に対して余裕がある。
- 印刷は軸の下端をベッドに立てる。フランジ下面の張り出し 1.5mm は 45° の面取りで自己サポートにする。

フランジ（φ9）はガイド筒（φ6.6）を通らないので、組立順は「カバーを被せる前にキャップを屋根の穴へ内側から差し込む」になる。組立手順に明記する。

印刷部品は プレート / ペデスタル / ソケット / トレイ / カバー / ボタンキャップ の 6 点になる。

## 組立手順

順序に依存する箇所があるので明記する。

1. 基板へ部品をはんだ実装する（Pico はまだ挿さない）。
2. 基板をトレイの支柱 4 本へ M2 で留める。この時点なら (33, 20.5) の穴にドライバーが入る。
3. Pico をメスソケットへ挿す。
4. ペデスタルをプレートへ M2×4 で留め、サーボを天板へ M2×2 で留める。
5. トレイをプレートへ M2×4 で留める。サーボのケーブルを基板の 3pin へ接続する。
6. ボタンキャップをカバーの屋根の穴へ**内側から**差し込む（フランジ φ9 はガイド筒 φ6.6 を通らないため、外側からは入らない）。
7. カバーを被せ、四隅のラグへ M2×4 で留める。

分解は逆順。カバーの 4 本を抜けば殻ごと真上に持ち上がる。

## 印刷方向

- カバー: **天面をベッドに伏せる**。屋根が第 1 層になるためブリッジが発生せず、45° の勾配面も自己サポートで刷れる。サポート不要。
- ボタンキャップ: フランジ面をベッドへ。
- プレート / トレイ / ペデスタル / ソケット: 現行と同じ向きで変更なし。

屋根に水平な段（二段屋根）を作れないのは、低い側の屋根が第 1 層より下に宙で現れて垂れるため。単一勾配にしているのはこの制約による。

## 重量とバランス（TASK-6 への影響）

壁 2.0mm での概算。

| 部品 | 現行 | 改修後 |
| --- | --- | --- |
| プレート | 約 53g | 約 30g |
| トレイ | 約 30g | 約 15g |
| カバー | — | 約 70g |
| 差引 | | **約 +32g** |

平天井（全高 75mm 一定）にすると約 94g で、45° 勾配にすることで約 24g 削れる。

プレートが 115.8×153.1 から 83.2×123.2 に縮むことで重心はドア面側・軸側に寄るが、**面ファスナーの接着面積も同じ比率で減る**。TASK-6（上から剥がれる）が改善するとは断言できない。実機で確認し、駄目なら面ファスナーの配置・種類で対応する。この設計では解決しない、というのが正直なところ。

## 新規 assert

削除する BB 系 assert の代わりに置く。

- 基板が受けカーブに干渉しない: `pcb_off_y - pcb_w/2 >= ped_curb_ro + 1`（`pcb_w` = 47 が Y 方向の寸法）
- 基板の支柱がトレイ床に収まる
- トレイ固定スリーブが 基板 / 受けカーブ / トレイ床端 のいずれとも干渉しない
- カバー内面が トレイ / ペデスタル / 基板 の外形を包含する
- 屋根内面の高さが各部品の上端を上回る（上表の 5 点）
- 屋根の勾配が 45° 以上（自己サポート成立）
- カバー固定ラグを含めたプレート最外がドアクリアランス内: `<= clear_left`, `<= clear_down`
- LED / SW の位置が基板内かつ既製マウント穴と干渉しない
- ボタンキャップの軸長が屋根内面 ⇔ スイッチ頭のすき間を渡る
