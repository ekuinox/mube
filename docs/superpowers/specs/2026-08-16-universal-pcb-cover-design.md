# ユニバーサル基板化＋全体カバー 筐体改修 設計書

日付: 2026-08-16

ブランチ: `enclosure/universal-pcb-with-lid`

関連: TASK-4（回路のユニバーサル基板化）、TASK-6（本体上部が重く固定が上から剥がれてくる）

## 目的

1. 電子部品の実装をブレッドボードからユニバーサル基板 P-03229（72×47mm）へ移す。トレイをその基板マウントに作り替える。
2. 配線がむき出しの現状をやめ、プレート上の全部品を覆う一体カバーを新設する。
3. 上記に伴いプレート外形を再設計する。ブレッドボードと Pico を横並びに置く前提が消えるため、大幅に縮められる。

## 背景

- 現行は「オープンベースプレート」構成（PR #79）。プレート（`body.scad`）にペデスタル・ソケット・トレイをボルトオンし、外周壁も蓋も持たない。配線は完全に露出している。
- 現行トレイはハーフサイズのブレッドボード（85.5×54.5）と Pico（51×21）を **横並び** に載せる前提で、これがプレート 115.8×153.1mm という大きさを決めていた。
- TASK-4 で「Pico は基板に直付けせず、Pico 側にオスピンヘッダ・基板側にメスソケットで抜き差しする」ところまで決まっている。Pico が基板の上に重なるので、電子部品エリアのフットプリントは基板 1 枚ぶん（72×47）に縮む。
- P-03229 の既製マウント穴は φ3.2、中心間ピッチ 長辺 66mm × 短辺 41mm（docs/parts-selection.md）。

## 決定事項

ブレインストーミングで確定した内容。

- カバーは **1 部品**。サーボ・ペデスタル・基板・配線のすべてを覆う。
- 屋根は **+Y 方向への単一勾配（45°）**。水平な段は作らない。
- カバーの固定は **M2 × 4 本**。カバー裾の外側に張り出した耳を、プレート上面の固定ボスへ落とす。位置は −Y の 2 隅と ±X 壁上の 2 点（四隅ではない。理由は後述）。
- カバー開口は **屋根斜面のハニカム・押しボタンスイッチ・USB 切欠き** の 3 つ。サムターンの手動操作窓は設けない（手動操作はカバーを外して行う）。
- LED 用の専用窓は設けない。基板上の LED の実装位置が未定で窓を一点に決められないため、**屋根の斜面を六角メッシュにして光をどこからでも逃がす**。平天面は開けない（後述の印刷方向）。
- スイッチは基板実装のタクトスイッチをやめ、**パネル取付の押しボタン PS21B-1（秋月 P-04583）をカバーに直付け**する。基板とは 2 本の線で繋ぐ。取付面は**平天面のサーボの脇**（斜面ではない）。
- **トレイは残す**。基板を机上で組んでからプレートへ載せられる利点を維持する。カバーとは独立に着脱できる。
- 基板は **横置き**（長辺 72 を X 方向）。縦置きよりプレートの Y 方向が短くなり、重心が低くなる。

原点はサムターン軸（ロゼット中心）。z=0 がドア面。既存の座標系をそのまま引き継ぐ。

法線方向に貫く材料の厚みはちょうど `cover_wall` = 2.0** である（屋根のハニカムが貫くのは
こちら）。スイッチは平天面に鉛直で付くので、そのネジ部が挟むパネル厚は 2.83 の方になる。

## 平面レイアウト

### 基板（P-03229, 72 × 47）

世界座標で X: −27〜45、Y: 35.3〜82.3。中心は (9, 58.8)。

- −Y 端がペデスタル受けカーブ外周（`ped_curb_ro` = 27.7）から `pcb_ped_gap` = **7.6mm** 逃げる。
  この 7.6 は「基板とカーブのすきま」を直接決めた値ではなく、−Y 側のトレイ固定スリーブの
  位置から逆算された結果である。スリーブの中心は `tray_fix_y_lo` = 30.7 で、その上端が
  30.7 + 3.9 = 34.6。基板 −Y 端 35.3 はこれを 0.7 かわす。そしてスリーブ自身がここまで
  +Y に押し上げられているのは、ペデスタルのフランジローブ（45°/135°、先端円の上端 y = 26.21）
  からトレイ床を逃がした結果。つまり支配しているのはペデスタルのローブであって基板ではない。
- 既製マウント穴 4 個は基板ローカルで (±33, ±20.5) ＝ 世界座標 (−24, 38.3) (42, 38.3) (−24, 79.3) (42, 79.3)。

### 基板上の部品配置（基板ローカル座標）

配置は `circuit/parts.ts` のネットリストと Pico W のピン配置から導いた。使用ピンは VBUS / GND / GP14〜GP18 で、**GP14〜GP18 は 5 本とも USB と反対側の端に固まる**（GP14=19 番、GP15=20 番、GP16=21 番、GP17=22 番、GP18=24 番）。VBUS だけが 40 番＝USB 端。

これで Pico の向きが一意に決まる。USB を +X へ向け、1〜20 番列（GP14 / GP15）を **−Y 辺**、21〜40 番列（GP16 / GP17 / GP18 / VBUS）を **+Y 辺** に向ける。結果、LED とスイッチの系統は +Y 側だけで、ゲート駆動とサーボ信号の系統は −Y 側だけで閉じる。

| 部品 | 位置 | 根拠 |
| --- | --- | --- |
| U1 Pico W | 長辺を X に、Y 中央。x −15〜+36 | USB を基板 +X 端に face させる。メスソケット列が y = ±8.89 に来るので既製穴（y = ±20.5）と干渉しない |
| D1 2色LED | (−24, +21) ＝世界 (−15, 79.8) | GP16 / GP18 の近く。屋根がハニカムなので窓に合わせる必要はなく、実装時に動かしてよい（ただし「LED の見え方」の項の 3 帯は避ける） |
| Rled 330Ω | (−22, +13) | GP16（21 番）直近 |
| Rled2 330Ω | (−28, +13) | GP18（24 番）直近 |
| SW1 用 2pin コネクタ | (−10, +21) ＝世界 (−1, 79.8) | GP17（22 番）直近。スイッチ本体はカバー側 |
| C1 470µF | (+26, +17) ＝世界 (35, 75.8) | V5 ＝ VBUS（40 番、+X 端）直近。サーボの突入を受けるバルクコンなので引き回しを最短にする |
| C2 100nF | (+20, +17) | C1 に隣接（parts-selection.md の指示） |
| Q1 MOSFET | (−27, −17) | GP14（19 番）直近。背が高い（基板上 16mm）が屋根は −Y 側ほど高いので問題ない |
| Rg 220Ω | (−22, −13) | GP14 ⇔ Q1.G の間 |
| Rgs 10kΩ | (−27, −11) | Q1.G ⇔ GND |
| D2 1N5819 | (−8, −19) | SERVO_RTN（Q1.D）とサーボコネクタの間 |
| サーボ 3pin | (+2, −21) ＝世界 (11, 37.8) | 基板の −Y 端。ペデスタルが隣なのでケーブルが最短で降りる。SIG は GP15（20 番、−Y 辺）直近 |

背の高さについては、屋根が +Y へ 45° で降りるので **y が大きいほど置ける部品が低くなる**。
モデル側が持っている予算は 3 段階:

| 予算 | 値 | 置ける範囲 |
| --- | --- | --- |
| `pcb_stack_tall`（TO-220 立て） | 16.0 | 世界 y ≤ `pcb_tall_y_max` = 78.4。基板 +Y 端まで残り 3.9mm の帯には置けない |
| `pcb_stack_mid`（C1 φ8×11.5 / LED φ5×8.6） | 12.0 | 基板上のどこでも可（+Y 端 82.3 でも屋根内面 25.5 に対し 2.1 の余裕） |
| `pcb_stack_low`（抵抗・ダイオード） | 3.0 | 基板上のどこでも可 |

パネル取付スイッチを平天面へ移したので、**基板上にスイッチのキープアウト帯は無くなった**。
本体は世界 x 26.25〜37.75 / y −5.75〜5.75 の鉛直な柱で、基板（y ≥ 35.3）の外を通る。
屋根の斜面がハニカムで抜けていることも、部品高さの予算には影響しない。抜けているのは
材料であって空間の余裕ではないので、上表はそのまま読む。

Pico を基板の +X 端まで寄せると (33, 20.5) の既製穴が Pico に近づく。ただし Pico は
基板ローカルで y ±10.5 にしか広がらず、穴は y 20.5 なので **10mm 離れており影には入らない**。
それでも「基板を 4 本のネジで留めてから Pico を挿す」順序は守る（挿した Pico を跨いで
ドライバーを立てるより素直で、ソケットに横力をかけずに済む）。組立手順の 2 を参照。

### トレイ

- 床: X −27.5〜45.5、Y 26.7〜90.9、厚さ 2.4。原点まわりを半径 29 で丸く欠き取り、ペデスタル受けカーブ（半径 27.7、高さ 2.4）をまたぐ。
- 基板支柱 4 本: 世界座標 (−24, 38.3) (42, 38.3) (−24, 79.3) (42, 79.3)、高さ 5、外径 5、下穴 φ2.1（`tray_screw_pilot` と同仕様）。

基板の既製穴は φ3.2 だが、留めるネジは **M2 で統一する**。理由は既存モデルに校正済みの実績があること。`pilot_gauge.scad` と `tray_pilot_gauge.scad` で M2 セルフタップの下穴径を実機で詰めてあり（サーボ耳 2.2、ボス 2.1）、貫通クリアランス 2.4 と頭ザグリ 4.2 も M2 基準で全部品に行き渡っている。BOM のネジも M2×5 の 1 種類だけ。M3 を持ち込むと下穴の校正クーポンを刷り直すところからになる。φ3.2 の穴に M2 を通すとネジ山は効かないが、頭（φ4.2）が基板を支柱へ押さえ付けるので保持には足りる。
- プレート固定スリーブ 4 個: (−22, 30.7) (40, 30.7) (−22, 86.9) (40, 86.9)。既存の `m2_sleeve_solid()` / `m2_sleeve_cuts()` をそのまま流用する。

固定スリーブを基板の ±Y 側に置いたのは、±X 側に置くとプレートの −X 端がドア枠へ寄りすぎるため。−X 側は `clear_left` = 50 の制約があり、カバーの裾と耳を積み上げると余裕がなくなる。±Y 側は制約が緩い。

−Y 側の 2 個（y = 30.7）は、ペデスタルのフランジローブとの干渉ぎりぎりに置かれている。
ローブは (±21.21, 21.21) 中心・半径 5 の先端円を持ち、上端が y = 26.21 まで来る。ここから
トレイ床（`tray_y0` = 30.7 − 3.9 − 0.1 = 26.7）を 0.3 のマージンで逃がすと、スリーブ中心の
下限は 30.513 になる。採用値 30.7 の余裕は 0.187 しかない。スリーブ中心間の距離も
ローブ半幅込みの下限 9.4 に対して 9.519（余裕 0.119）で、この帯の定数はどれも動かすと
assert が鳴る。

### プレート

- 本体外形: X −38.0〜55.8、Y −38.0〜96.2（**93.8 × 134.2mm**）、角R `cover_round_r` = 2、厚さ 2.4。
  **素の角丸矩形**であり、張り出しは一切ない。
- 外形の各端は「外周リブの矩形」と「耳＋そのまわりの肉」の両方を包む（`params.scad` の
  `plate_x0` … は両者の min / max）。
  - 外周リブの矩形（`plate_rib_x0` …）= X −33.0〜50.8、Y −33.0〜96.2。カバー裾の外面
    （−30.7 / 48.5 / −30.7 / 93.9）＋ リブ幅 2 ＋ 嵌合すきま 0.3。
  - 耳＋肉 = `cover_ear_pts` の 4 点 ± `plate_ear_r` = スリーブ外径の半分 3.9 ＋
    `plate_ear_pad` 0.6 = 4.5。すなわち X −38.0〜55.8、Y −38.0〜91.4。
  - 結果、−X / −Y / +X は耳が、+Y はリブ矩形が外形を決める。
- カバー固定ラグは**廃止**した（旧 φ`plate_lug_d` = 9 の張り出し円 4 個）。詳細は下記。
- 中央ロゼット開口・ペデスタル受けカーブ・ペデスタル固定ボス 4 本は現行のまま不変。
- トレイ固定ボス 4 本とカバー固定ボス 4 本は `m2_boss()` を流用（高さ 6、袋下穴でドア面を貫通しない）。
- 上面リブ: 周回のみ、横桟なし。リブ（**リブ矩形**の内側 2mm、高さ 4）が **カバー裾の位置決め
  リップを兼ねる**。リブの内面（−30.7 / 48.5 / 93.9）がカバー裾の外面を受け、カバーがリブの
  内側に落ちる。プレート外形が広がってもリブの通り道は動かさない（動かすとリップが裾から
  5.3mm 離れて位置決めが効かなくなる）ため、`plate_outline_2d()` とは別に
  `plate_rib_outline_2d()` を持つ。−X / −Y / +X 側ではリブがプレートの縁から 5mm 内側を走る。

STL 実測のバウンディングボックスは **93.8 × 134.2 × 8.4mm**（X −38.0〜55.8、Y −38.0〜96.2）。
ドアクリアランス（`clear_left` = 50、`clear_down` = 65）に対してそれぞれ **12.0mm / 27.0mm**
の余裕が残る。`params.scad` 末尾の `-plate_x0 <= clear_left` / `-plate_y0 <= clear_down` が
これを守る。ラグがあった頃はこの 2 本が矩形本体（−33.0）しか見ておらず、実際の最外である
ラグ（−38.0）を取りこぼしていた（「中心をサンプリングして極値を見落とす」欠陥の一種）。
外形が素の矩形になったことで `plate_x0` / `plate_y0` がそのまま実際の最外になり、
別立てのラグ用 assert が不要になった。

**ラグを廃止した理由。** ラグ込みの実測バウンディングボックスがすでに 93.8 × 134.2 で、
そこまで矩形を張り出させても**外形封筒は 1mm も増えない**。増えるのは四隅の空き地ぶんだけで、
実測 27.44 → 31.25 cm³（34.0g → **38.8g**、+4.7g）に収まる。得られるのは 2 つ。

- φ7.8 のスリーブが載る φ9 の張り出しという細い首が無くなる（見た目にも実際にも折れにくい）。
- 「ラグが本体矩形の丸め offset で橋渡しされず、4 枚の独立した円盤に分離する」破綻モードが
  丸ごと消える。これを守っていた
  `assert((cover_ear_off - plate_margin + cover_round_r)*sqrt(2) - cover_round_r < plate_lug_d/2)`
  も一緒に削除した。

TASK-6（上部が重く面ファスナーが上から剥がれる）を理由にプレートの材積を切り詰めてきたが、
実機では面ファスナーが想定よりずっとよく保っていることが確認できたので、この +4.7g は許容する。

**固定点を四隅に置かない理由。** +Y の 2 個は角ではなく ±X 壁上の y = `tray_fix_y_hi` = 86.9
（トレイ +Y 固定点と同じ y）に降ろしてある。角（y = 96.7）に置くと、カバー側の耳の天面
（z = 12.2）が、耳の +Y リム（96.7 + 3.9 = 100.6）における屋根外面（z = 10.03）を突き抜ける。
カバーは天面をベッドに伏せて刷るので、突き抜けた耳はベッドから 63mm 浮いた孤立島になり、
サポート無しでは刷れない。y = 86.9 なら屋根外面が 23.73（リムでも 19.83）で、耳は壁の
高さにすっぽり収まる。おまけに直線の壁には角丸めの引っ込みが無いため、耳の円が裾の外面へ
1.1mm 食い込んでウェブ無しで裾と一体になる（−Y の 2 隅は角丸めのぶん 0.89mm 浮くので
`cover_ear_webs()` が橋を架けている）。

なおこの判定は必ず耳の **リム** で行うこと。中心（y 96.7）だけを見ると屋根外面は 13.93 で
耳天面 12.2 を上回り、突き抜けが見えない。本改修で 3 度踏んだ「中心をサンプリングして
極値を見落とす」失敗と同じ形である。

**横桟を全廃した理由。** 横桟はプレート全幅に走るので、カバーの −X / +X 側壁の真下を
貫いてしまい、カバーが座らない。よって `plate_rib_ys = []` として全廃し、剛性は M2 で
留められたカバーが肩代わりする。残る周回リブも、カバー固定ボス 4 点の周りを
φ(`tray_sleeve_od` + 1) = 8.8 で丸ごと逃がすため辺を数 mm ずつ食われ、
実体は **閉じた一周ではなく 4 本の独立した直線区間** になる。位置決めリップとしては
X・Y 両方向を直線区間で拘束するので機能上の問題はない。

逃げ径の下限はかつて `plate_lug_d + 0.2` = 9.2 だった（逃げがラグ輪郭より小さいと、その
差ぶんの三日月壁がノズル幅未満で残るため）。ラグを廃止したのでこの下限は不要になり、
`tray_sleeve_od + 1` = 8.8 だけになった。半径 4.4 は、耳の中心からリブ帯の外縁までの
最遠点（−Y 隅の角R 中心まで 3.54）を上回るので、各点でリブ帯を完全に断ち切る
（`body_test.scad` の `rib_corner_far` の assert が守る）。

## カバー

### 外形

footprint は角R `cover_round_r` = 2 の矩形。内面 X −28.7〜46.5、Y −28.7〜91.9。
壁厚 2.0 で外面 X −30.7〜48.5、Y −30.7〜93.9。

屋根は y ≤ `cover_slope_y0` = 34.9 の範囲が水平（外面 z = 75.73 / 内面 z = 72.9）で、
そこから +Y へ 45° で降りる。

```
 z(内面)
 73 ┤   ┌─────────┐
    │   │ サーボ   ╲
    │   │          ╲ 45°
 38 ┤   │           ╲             ← Pico +Y 端(y 69.3)。スタック 23.4 に対し 15.1
    │   │            ╲
 25 ┤   │             ╲___        ← 基板 +Y 端(y 82.3)。C1/LED 23.4 に対し 2.1
 16 ┤   │                 ╲|      ← +Y 端の壁（内面 y 91.9 で z 15.9）
  0 ┴───┴──────────────────┴──→ y
   -28.7 34.9              91.9
```

内面天井の高さは `z = 72.9 − max(0, y − 34.9)`（`roof_in_z()`）。主要な干渉点の余裕。
**各行は部品の中心ではなく、拘束方向（+Y）における部品の極値で評価している**：

| 評価点 | 部品 | 部品上端 | 屋根内面 | 余裕 |
| --- | --- | --- | --- | --- |
| y ≤ 34.9（平天井域） | サーボ本体上端 | 70.9 | 72.9 | 2.0 |
| y 78.4（`pcb_tall_y_max`） | MOSFET (TO-220 立て) | 27.4 | 29.4 | 2.0 |
| y 69.3（Pico の +Y 端） | Pico / USB コネクタ | 23.4 | 38.5 | 15.1 |
| y 82.3（基板の +Y 端） | C1 / LED（`pcb_stack_mid`） | 23.4 | 25.5 | 2.1 |
| y 90.8（スリーブの +Y リム） | トレイ +Y 固定スリーブ天面 | 12.2 | 17.0 | 4.8 |
| y 90.9（トレイ床 +Y 端） | トレイ床上面 | 4.8 | 16.9 | 12.1 |

マージンを要求すると下限が 34.8 になり、この定数の慣習どおり 0.1 を足して 34.9 を手置き
している。評価点を C1 の実座標ではなく基板の +Y 端に取っているのは、基板上の部品配置が
モデル化されておらず（はんだ実装は TASK-4 でこれからやる作業）、配置が動いても assert を
書き換えずに済ませたいため。「12mm 以下の部品なら基板のどこに置いてもよい」という
不変条件として読む。

スイッチ本体は屋根とも基板とも当たらず、ペデスタルとサーボが相手になるので上表とは別枠。
平天面から φ11.5 の円柱を鉛直に 26mm 落とした柱（世界 x 26.25〜37.75 / y −5.75〜5.75 /
z 49.73〜75.73）で、下記の「スイッチ」の項で見る。

**屋根のハニカム**

LED の実装位置が基板上でまだ決まっていないので、専用の窓を一点に決めず、斜面全体を
六角メッシュにして光を逃がす。定数は `cover_mesh_af` = 5.0（対辺距離）、
`cover_mesh_web` = 3.0（隣り合う穴の平らな辺どうしに残る桟）、`cover_mesh_margin` = 4.0
（斜面の縁から残すソリッドの幅）。

桟は当初 2.0 で起こしたが、レンダリングを見ると桟が細く頼りなかったので **3.0 へ太らせた**。
ノズル 0.4 換算で 5 パス → 7 パス。格子間隔が 7.0 → 8.0 に広がるので、六角の数・位置・
帯に収まる範囲がまるごと変わる（105 個 → 77 個）。開口率は斜面の内面積
（`cover_x0`〜`cover_x1` × 斜距離 0〜80.610 = 6061.9mm²）に対し **37.5% → 27.5%** に下がるが、
LED の光を逃がすという目的には足りる。

- **穴の軸は鉛直ではなく斜面の法線**。`rotate([-45,0,0])` がシリンダ軸 (0,0,1) を外向き法線
  (0, √2/2, √2/2) に一致させ、同時に回転後のローカル xy が斜面そのものになる。したがって
  材料は斜めに切られず、穴の長さはどれも `cover_wall` = 2.0 ちょうど。
- **開けるのは斜面だけ**。平天面はベッド接地面なので開けない（印刷方向の項）。これは
  マージンが `cover_wall` を上回ることで保証される。穴は法線方向のプリズムなので、稜線から
  斜距離 v にある穴は **v ≤ `cover_wall`** のとき平天面のスラブを貫く。マージン 4.0 は
  この境界 2.0 に対して 2.0 の余裕があり、`assert(cover_mesh_margin > cover_wall)` が守る。
- **範囲**は稜線・+Y 内壁・±X 内壁から 4mm のソリッドを残した帯。ローカル座標（x = 世界 x、
  y = 稜線からの斜距離）で x −24.7〜42.5、y 4〜76.61。+Y 側の基準を外面（93.9）ではなく
  内面（`cover_y1` = 91.9）に取るのは、屋根が板として自立しているのがそこまでで、その先は
  +Y 壁の肉に載っているため。斜距離 76.61 = (91.9 − 34.9) × √2 − 4。±X も同じ理由で
  内面（`cover_x0` / `cover_x1`）基準。
- **格子**は間隔 8.0（= 5.0 + 3.0）の三角格子。列を 8.0 × √3/2 = 6.93 ごとに並べ、隣の列を
  4.0 ずらす。どの隣接方向でも中心間距離が 8.0 になるので、平らな辺どうしに残る桟はどこも
  3.0 ちょうどになる。
- **縁で半端に切られる六角は落とす**。外接矩形（±2.887 × ±2.5）が上の帯に収まるものだけを
  残す。切り欠かれた六角は縁ぞいに極細のスライバを作り、0.4mm ノズルでは繋がらないため。
  結果として 77 個が残り、実際に置かれた六角の外周は x −21.700〜39.500、
  斜距離 5.805〜74.805。**実体の壁（内面）までの残り**は四方とも要求の 4mm を上回る。

  | 方向 | 実体の基準面 | 六角の最外 | 残り（桟 2.0 の頃） |
  | --- | --- | --- | --- |
  | −X | `cover_x0` = −28.7（内面） | −21.700 | 7.000（4.402） |
  | +X | `cover_x1` = 46.5（内面） | 39.500 | 7.000（4.402） |
  | 稜線 | 斜距離 0 | 5.805 | 5.805（6.305） |
  | +Y 壁 | 斜距離 80.610（= `cover_y1` 内面） | 74.805 | 5.805（6.305） |

  格子間隔が変わると「帯に丸ごと収まる六角」の並びごと動くので、実現するマージンも一緒に
  動く。±X は 4.402 → 7.000 と厚くなったが、**稜線側と +Y 壁側は 6.305 → 5.805 と 0.5mm
  薄くなっている**。要求値は `cover_mesh_margin` = 4.0 なので依然 1.8mm の余裕があり、
  ベッド接地面（平天面）に穴が開く条件（斜距離 ≤ `cover_wall` = 2.0）からも遠い。伏せ印刷で
  最初の六角が現れる高さは 6.305/√2 = 4.46mm → 5.805/√2 = **4.10mm**（0.2mm 層で 20 層）で、
  定着に効く序盤がソリッドである点も変わらない。
- **検証**: 屋根板の中央（法線方向に 1.0 内側）で水平にスライスした 2D 断面を SVG に出して
  実測した。輪郭は 78 個（六角 77 + 外形 1）、六角の対辺距離はどれも 5.00000〜5.00005、
  異なる輪郭どうしの最小距離は **2.99993mm**（＝設計値 3.0。差 7e-5 は SVG 出力の座標丸め）。
  半端に切られた六角（頂点数 6 以外の輪郭）は 1 つも無い。なおこの断面の「外形」輪郭は裾の
  **外面**（x −30.7〜48.5）なので、六角からそこまでの距離を縁のマージンの根拠にしては
  いけない。マージンの基準は上表のとおり**内面**である。

**スイッチ（PS21B-1 / 秋月 P-04583）**

パネル取付のモーメンタリー押しボタン（OFF-(ON)、A 接点）。カバーの平天面に開けた穴へ外から差し込み、内側からナットで締める。基板とは 2 本の線で繋ぐ。

| 項目 | 値 |
| --- | --- |
| キャップ | φ14 × 高さ 7.6（パネル面より外） |
| フランジ | φ18.7 × 厚さ 3.5 |
| ネジ部の長さ | 8.3（ナットを除き挟めるパネル厚は約 5.8） |
| パネル面より内側の奥行き | 26（旧ロット図 37.0 − 7.6 − 3.5。2017 年図の 22.4 より厳しい方を採用） |
| ネジ部の外径 | φ11.5（実測 2026-08-16。旧ロット図の 11.50 と一致）。取付穴は印刷公差を見て φ12.0 |

取付位置は **平天面の (32, 0)＝サーボの脇**。斜面をハニカムにして穴を置ける平らな面が
残らなくなったので移した。平天面なら軸を鉛直に取れて、奥行き 26mm がまっすぐ下へ降りる。

本体は φ11.5 の円柱を天面 z = 75.73 から鉛直に 26mm 落とした柱で、世界
x 26.25〜37.75 / y −5.75〜5.75 / z 49.73〜75.73 を占める。**円柱の底面は水平なので、
下端は軸上でも縁でも 49.73 で同じ**（斜面に付けていた頃のように最下点が軸から外れることは
ない）。かわす相手は 3 つ。

| 相手 | 極値の取り方 | 値 | 余裕 |
| --- | --- | --- | --- |
| ペデスタル天板 | 天板上面（`pedestal_top_z`） | 48.4 | 柱の底面 49.73 に対し **1.33** |
| ペデスタル筒 | 筒外半径（`pedestal_outer`） | 25.4 | 柱の軸に最も近い点 32 − 5.75 = 26.25 に対し **0.85** |
| サーボ | +X の極値は本体（16.65）ではなく**耳の先端** `servo_shaft_offset + servo_tab_l/2` | 21.5 | 柱の −X 端 26.25 に対し **4.75** |

サーボは z 48.4〜70.9 で柱と z が重なるので、xy で離すしかない。ペデスタルは逆に z だけで
かわせている（筒の天面が 48.4 で柱の底面 49.73 より低い）が、半径側の 0.85 も併せて
assert に書いてある。`sw_depth` が伸びた途端に効くのは半径側の方である。

基板とは当たらない。基板は y ≥ 35.3 にあり、柱の y は −5.75〜5.75 なので重なりが無い。

平天面に付くので、**実効パネル厚は 2.83mm**（= `cover_top_z − cover_inner_top`
= `cover_wall` × √2）である。斜面に付けていた頃は軸が法線方向で材料が斜めに切られず
2.0mm だったが、鉛直に貫く平天面ではこちらになる。ネジ部 8.3mm に対しては
どちらにせよ十分で、ナットに 5.47mm が残る。

座面の **φ19 のザグりは実装していない**。平天面は単一の水平面であり、座面の範囲
（x 22.5〜41.5、y ±9.5）は全域がその平面上にあるので、ザグらなくても最初から平らである。
フランジ φ18.7 はそのまま座る。座面が斜面へかからないこと（y + 9.5 ≤ `cover_slope_y0`
= 34.9）と、内側でナットを締める平面がカバー内腔の範囲にあること（x/y とも
`cover_x0`〜`cover_x1` / `cover_y0` 以内）を assert が守る。

**嵌合クーポン**: カバーは 80g 級の大物なので、穴径とパネル厚の当たりを確かめるためだけに
全体を刷るのは高くつく。取付部だけを切り出した `sw_mount_coupon` を先に刷る（下の「検証」
参照）。

**カバーと基板の切り離し**: スイッチがカバー側に付くため、カバーは 2 本の線で基板に繋がれる。線の端を 2pin のピンヘッダ／ソケットにして抜き差しできるようにする。ピンヘッダは既に BOM にあるので部品追加はゼロ。カバーを外したら線を抜いて完全に分離できる。

**LED の見え方**

LED 専用の窓は廃した。屋根の斜面が一面のハニカムなので、LED を動かしても、その真上の斜面
から光が抜ける。以前この項にあった「窓の内口と LED の頭の位置関係」「足を何 mm 伸ばせるか」
「真上からの見通し線」の議論は、窓が一点に決まっていたことに由来する制約であり、
**まるごと不要になった**。

ただし **「基板のどこでも」ではない**。メッシュの縁のマージンぶん、基板の外周には
真上がソリッドの帯が残る。覆われていないのは次の 3 帯で、この中に LED を置くと真上には
穴が来ない（斜め上のメッシュからは抜ける）。

| 覆われない帯（世界座標） | 幅 | 理由 |
| --- | --- | --- |
| y 35.3〜39.01（基板の −Y 端側） | 3.71 | 稜線側マージン。y 39.01 = 34.9 + 5.805/√2 |
| x −27〜−21.70（基板の −X 端側） | 5.30 | −X 側マージン |
| x 39.50〜45（基板の +X 端側） | 5.50 | +X 側マージン |

基板の +Y 側は覆われている（メッシュの +Y 端は世界 y 87.80 で、基板の +Y 端 82.3 より外）。
D1 の公称位置 (−15, 79.8) はどの帯からも十分内側にある。桟を 3.0 へ太らせて開口率が
27.5% に下がったぶん、LED の真上に桟が来る確率は上がるが、六角の間隔は 8.0mm しかないので
斜め上の穴からは必ず抜ける。

残る制約は屋根内面の高さだけで、これは上の「主要な干渉点の余裕」の表がそのまま持つ。
LED（φ5 × 8.6）は `pcb_stack_mid` = 12.0 の予算内なので基板のどこにでも置けて、
足を伸ばすなら 12.0 − 8.6 = **3.4mm** までという上限も予算から出る（`pcb_stack_mid` を
超えると屋根内面に当たる。判定は部品の中心ではなく +Y 側のリムで行うこと）。

### 固定

裾の外面から張り出す耳 4 個。耳の実体は `m2_sleeve_solid()` / `m2_sleeve_cuts()` をそのまま流用する（ボス逃げボア＋自己サポートファンネル＋頭ザグリ、トレイとペデスタルで実機検証済みの構造）。中心はプレートのラグ中心と一致させる。

配置は **−Y の 2 隅 ＋ ±X 壁上の 2 点（y = 86.9）**。四隅ではない。理由は「プレート」の項に
書いたとおり、+Y の角に置くと耳がその位置の屋根を突き抜けて伏せ印刷で孤立島になるため。
−Y の 2 隅は角丸め（`cover_round_r` = 2）のぶん耳の円が裾から 0.89mm 浮くので、
`cover_ear_webs()` が「最寄りの角の丸め円 ⇔ 耳の円」の凸包だけで橋を架ける。裾の外形全体と
凸包を取ると耳から遠い辺まで接線で結ばれて側壁の外にヒレが生えるので、対象は角ごとに絞る。
この橋が無いとカバーの STL は連結成分が 5 個に割れる（`components.ts` が検出する）。

**耳のガセット（45°）**

耳は裾の外面から最大 6.7mm 片持ちで張り出し、その天面（z = `cover_ear_top_z` = 12.2）は
**M2 の頭の座面**である。カバーは天面をベッドに伏せて刷るので、この天面はワールドで「上に
何も無い」＝印刷では下向きの完全な水平面として、ベッドから 63.5mm の高さに宙で現れる。
STL で実測すると 4 個で **149.4mm²**（ベッド接地面を除いた水平な下向き面の 64%）あった。

対策として、耳の天面から裾の外面へ 45° で立ち上がるガセットを足す（`cover_ear_gussets()`）。
これは印刷の都合だけでなく、φ7.8 の棒が厚さ 2.0 の壁から出ているという**根元の細さ**への
補強でもある。形は「その高さでの裾外面の外側オフセット」で切った断面の積み重ね:

```
z = cover_ear_top_z + t の断面 = 耳のフットプリント ∩ offset(裾の外面, H - t)
```

オフセットの相手は凸（直線壁 / 角の丸め円）なので断面は単調に縮み、どの層も 45° 以内で
内側へ寄る。`t = H` で断面が裾の肉そのものと一致して終わる＝ガセットの天は裾に載る。

| 耳 | 相手 | 高さ `H` |
| --- | --- | --- |
| ±X 壁上の 2 点 | 直線の壁外面（平面オフセット＝45° の斜め半空間で削ぐ） | `cover_gusset_h_wall` = `cover_ear_off` + 3.9 = **6.7** |
| −Y の 2 隅 | 角の丸め円（同心円オフセット＝45° のコーンで削ぐ） | `cover_gusset_h_corner` = (`cover_ear_off` + 2)×√2 + 3.9 − 2 = **8.688** |

−Y 隅では断面に耳の円ではなく「角の丸め円 ⇔ 耳の円」の**凸包**（= `cover_ear_webs()` と
同じフットプリント）を使う。ウェブの天面も同じ z = 12.2 にあり、一緒に支える必要があるため。
ウェブ（z 6.8〜12.2）とガセット（z 12.2〜20.9）は面で接して積み上がる。

**ドライバの逃げ。** M2 は耳の天面から真下へ入るので、頭ザグリ（φ`tray_head_d` = 4.2）を
ガセットの上まで真っ直ぐ延長する（`cover_ear_driver_bores()`）。**径をザグリより広げては
いけない**。広げるとその段差がそのまま耳の天面の水平な張り出しとして戻ってきて、ガセットで
消した面積が復活する。同径なら段差ゼロで、軸まわりに φ4.2 × 3.9mm の穴が空くだけ。
穴は耳の中心から半径 2.1 しか広がらず、裾の外面までは 2.8 あるので裾は削らない。

干渉は起きない。ガセットの z 帯（12.2 以上）はプレートの外周リブ天面（6.4）とカバー固定ボス
天面（8.4）のどちらよりも上で、内腔は 2D の difference で抜いてある。+Y 側だけは屋根が
降りてくるので、`params.scad` の「+Y の耳／ガセットが屋根を突き抜ける」assert が
`cover_ear_top_z + cover_gusset_h_wall` = 18.9 ≤ 19.83（耳の +Y リムでの屋根外面）を守る
（余裕 0.93）。ガセットを足したことで、この assert は「屋根がトレイ +Y 固定スリーブの天面に
当たる」より **2.87mm 厳しい** 側へ入れ替わり、支配的な assert になった。

**効果（STL 実測）**: ベッド接地面を除いた水平（< 5°）な下向き面は 232.7 → **83.3mm²**。
消えたのはちょうど耳の 149.4mm² で、残る 83.3 は M2 の頭ザグリの座面 37.3・USB 切欠きの
天井 28.0・ファンネル上端の縮退面 18.1 という既存のもの。耳まわり（耳の軸から半径
2.2〜12mm、z 帯 7〜22）に限れば、最も水平に近い下向き面は **0.000° → 45.000°**、
45° を割る面積は **147.7 → 0mm²**。増える材積は 65.71 → 66.32 cm³（**+0.75g**）。

裾はプレート上面（z = 2.4）に着地し、外面が周回リブ（高さ 4）の内面に受けられて XY 位置決めされる。ネジは抜け止め専任。

印刷部品は プレート / ペデスタル / ソケット / トレイ / カバー の 5 点。現行から カバー 1 点だけ増える。

## 組立手順

順序に依存する箇所があるので明記する。

1. 基板へ部品をはんだ実装する（Pico はまだ挿さない）。
2. 基板をトレイの支柱 4 本へ M2 で留める。Pico を挿す前に済ませること。
3. Pico をメスソケットへ挿す。
4. ペデスタルをプレートへ M2×4 で留め、サーボを天板へ M2×2 で留める。
5. トレイをプレートへ M2×4 で留める。サーボのケーブルを基板の 3pin へ接続する。
6. スイッチ PS21B-1 をカバーの平天面の穴へ外から差し込み、内側からナットで締める。
7. スイッチの 2 本の線を基板の 2pin ソケットへ挿す。
8. カバーを被せ、プレートの固定ボス 4 本へ M2×4 で留める。ドライバはガセットを貫く
   φ4.2 の穴へ真上から差し込む。

分解は逆順。カバーの 4 本を抜き、2pin を抜けば殻が完全に分離する。

## 印刷方向

- カバー: **天面をベッドに伏せる**。屋根が第 1 層になるためブリッジが発生せず、45° の勾配面も自己サポートで刷れる。サポート不要。
  固定耳の天面だけは例外で、そのままだとベッドから 63.5mm の高さに宙で現れる水平面に
  なる（4 個で 149.4mm²）。これは「固定」の項のガセットで潰した。
- プレート / トレイ / ペデスタル / ソケット: 現行と同じ向きで変更なし。

屋根に水平な段（二段屋根）を作れないのは、低い側の屋根が第 1 層より下に宙で現れて垂れるため。単一勾配にしているのはこの制約による。

**ハニカムを斜面だけに開け、平天面はソリッドのまま残す理由も同じ向きから来る。** 平天面は
唯一のベッド接地面であり、第 1 層そのものである。ここを穴だらけにすると接地面積が減って
反りと剥がれを招くうえ、第 1 層が細い桟の集合になるので定着自体が怪しくなる。スイッチの
φ12 の穴 1 個までが許容範囲という判断で、光を通す開口は全部斜面に寄せた。

斜面のハニカムは印刷向きでも素直である。伏せた向きでの高さは
`print_z` = (v − z_local)/√2（v = 稜線からの斜距離、z_local = 法線方向）なので、**上になるのは
斜面ローカルの +y、つまり下り勾配（+Y）側**である。六角の向き（`$fn=6` の `circle` なので
頂点が ±x、平らな辺が ±y）だと穴の天井は +y 側の平らな辺が掃く面になり、この面は
ローカル x と法線が張る平面＝**ちょうど 45°**。面そのものが 45° なので、水平なブリッジは
どこにも現れず、各層のせり出しは層厚ぶんに留まる（自己サポート）。

ベッドから最初の六角が現れるのは `print_z` = 5.805/√2 = **4.10mm**（最も稜線寄りの六角の
外口）。`params.scad` の `servo_screw_pilot` のコメントが記録している実機条件（A1 mini /
0.4 ノズル / 0.2mm 層）なら、定着に効く序盤の 20 層あまりは無傷のソリッドで刷られる。

## 重量とバランス（TASK-6 への影響）

**すべて STL の実測値**（メッシュの符号付き四面体体積の総和）。密度は中身の詰まった PLA
1.24 g/cm³ とした。実際のプリントはインフィルで軽くなるが、比較の比率は変わらない。
「現行」は本ブランチの分岐元 `ab95b98` のモデルを同じ方法で測ったもの。

| 部品 | 現行 | 改修後 |
| --- | --- | --- |
| プレート | 45.89 cm³ / **56.9g** | 31.25 cm³ / **38.8g** |
| トレイ | 30.01 cm³ / **37.2g** | 12.08 cm³ / **15.0g** |
| カバー | — | 66.32 cm³ / **82.2g** |
| 計 | 75.90 cm³ / 94.1g | 109.65 cm³ / 136.0g |
| 差引 | | **+33.75 cm³ / +41.8g** |

プレートの 31.25 はラグを廃して素の矩形にしたあとの値（ラグ版は 27.44 cm³ / 34.0g で、
四隅の空き地ぶん **+4.7g**）。カバーの 66.32 は耳のガセットを足したあとの値
（ガセット無しは 65.71 cm³ / 81.5g で **+0.75g**）。

ペデスタル（23.52 cm³ / 29.2g）とソケット（19.39 cm³ / 24.0g）は本改修で変わらない。

以前この表は概算で「プレート 53g → 30g、トレイ 30g → 15g、カバー 70g、差引 +32g」と
書いていた。実測すると現行側も改修後側もそれぞれ重く、素の（ハニカム前の）正味の増加は
+32g ではなく **+41g** だった。TASK-6 は「上部が重くて上から剥がれる」問題なので、この
数字を甘く見積もってはいけない。

平天井（全高 75.73mm 一定）のカバーを実際にビルドして測ると 85.04 cm³ / 105.5g で、
45° 勾配にすることで **19.8g** 削れている（当初の概算「約 24g」に近い）。

`cover_slope_y0` を 31.2 から 34.9 へ上げた Ruling 12 のコストは 67.62 → 69.08 cm³、
すなわち **+1.8g**。全高（`cover_top_z`）は変わらず、平天面が +Y へ 3.7mm 伸びて斜面が
そのぶん短くなり、+Y 壁が 3.7mm 高くなるだけなので、材積の増減はほぼ相殺する。

屋根のハニカム化（＋ LED 窓の廃止・スイッチ穴の移動）で 69.08 → 65.71 cm³、すなわち
**−4.2g**。しかも削れているのは全部いちばん高い所の材料なので、重心にはこの数字以上に
効く。桟を 2.0 から 3.0 へ太らせた時点で開口率が 37.5% → 27.5% に落ち、この削減は
−5.7g から −4.2g へ 1.5g ぶん戻った。ただし正味は依然 +41.8g の増加であり、下の結論は
変わらない。

プレートが 115.8×153.1 から 93.8×134.2 に縮むことで重心はドア面側・軸側に寄る。
しかし外形の面積は **約 0.71 倍** に減るのに、総質量は **約 1.44 倍**
（75.90 → 109.65 cm³）に増える。つまり **面ファスナーの単位面積あたりの負担は倍以上に
なる**。さらにその増分の大半（82.2g）は上に乗るカバーで、上部が重くなる方向に働く。

当初この項は「TASK-6（上から剥がれる）が改善するとは断言できない、むしろ悪化を先に疑え、
この設計では解決しない」と結んでいた。その後の実機確認で、**面ファスナーは想定より
ずっとよく保っている**ことが分かったので、TASK-6 をこの改修の律速条件として扱うのはやめた
（ラグを廃してプレートを素の矩形にした +4.7g、耳のガセットの +0.75g はどちらもその判断に
乗っている）。とはいえ正味 +41.8g・重心上がりという事実は変わらないので、実機で経過を
見続けること。駄目なら面ファスナーの配置・種類で対応する。

### 段取り 8 を撤回した理由

tscircuit の ERC が検証するのは **導通だけ** である。フットプリントやシンボルのパッド数を
差し替えても、この検証が見る情報は 1 ビットも変わらない。したがって SW1 を「基板実装の
タクト」から「2pin コネクタ」へ描き替える作業には、検証上の利得がまったく無い。

よって `circuit/` 側のネットリスト表現は **意図的に据え置く**。SW1 のシンボルは 4 パッドの
押しボタンのままで、`netlist.tsx` の `ALLOW_UNCONNECTED` が `SW1.pin3` / `SW1.pin4` を
未接続として許容し続ける。

物理的な実態は「SW1 は基板外のパネル取付部品（PS21B-1）であり、基板とは 2 本の線＝2pin
コネクタで繋がる」であって、これは筐体側（`cover.scad` のスイッチ穴）と BOM

そこに物理実装の形を持ち込む必要はない。

この意図は `circuit/netlist.tsx` の `ALLOW_UNCONNECTED` のコメントに記録してある。
表示用のラベル（`circuit/breadboard/footprints.ts` の SW1 の `value`）だけは実物に合わせて
`"Tact"` → `"PS21B-1"` に直した。こちらは配線図を読む人間向けの表示であって、
ERC の入力ではない。
